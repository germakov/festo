# FESTO — городской музыкальный фестиваль

Адаптивный лендинг вымышленного музыкального фестиваля. Проект демонстрирует оформление мероприятия, презентацию артистов, расписание выступлений и выбор билетов.

## Возможности

- Адаптивная вёрстка для мобильных устройств и компьютеров.
- Мобильное навигационное меню.
- Программа фестиваля с расписанием выступлений.
- Карточки артистов.
- Три тарифа билетов.
- Выбор тарифа с переходом к форме заявки.
- Демонстрационная форма с сообщением о результате.
- Поддержка настройки уменьшения анимации.

## Технологии

- HTML5
- CSS3
- JavaScript

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Важно

Это демонстрационный проект. Покупка билетов, оплата и фактическая отправка заявок не реализованы.

## Статус

Учебный проект для портфолио веб-разработчика.
